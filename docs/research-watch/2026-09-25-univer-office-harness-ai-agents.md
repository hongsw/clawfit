# Research Watch: Univer — Office Harness for AI Agents

- Repo/Link: https://github.com/dream-num/univer
- Source: GitHub Trending

## Why this is worth watching
Univer positions itself as "The Office Harness for AI Agents" — a unified runtime hosting spreadsheets, docs, slides, canvas, relational tables, and PDF inside one agent-friendly surface. It crossed 17K stars with +1,082 in a single day, signaling sharp organic traction. This is a rare harness-layer project that targets the document/productivity surface rather than code or browser.

## What stands out immediately
- Combines six document types (spreadsheet, doc, slide, canvas, table, PDF) in one TypeScript runtime
- Explicitly markets itself as an agent harness, not just a UI library
- Built-in agent hook points for programmatic manipulation — tables, formulas, layouts
- TypeScript-first with a plugin/extension architecture suited for MCP wiring

## Why clawfit should care
If agents increasingly manipulate business documents (reports, spreadsheets, presentations), Univer becomes a candidate harness-layer tool for knowledge-work profiles. It sits at Level 2 (Harness/Wrapper) but targets output destinations like `internal_product` and `client_facing`. A future registry entry could target exec + analyst roles with research and content-creation tasks.
