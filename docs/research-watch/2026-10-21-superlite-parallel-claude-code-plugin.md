# Research Watch: Superlite

- Repo/Link: https://contextfirst.blog/superlite-hand-an-agent-a-spec/
- Source: GeekNews

## Why this is worth watching
A Claude Code plugin that reduces approval interruptions and sequential execution bottlenecks by enabling parallel implementation from a spec. It directly addresses "approval fatigue" — one of the top friction points in agentic coding workflows — and is positioned as faster than Superpowers.

## What stands out immediately
- Reduces approval count during long coding sessions
- Enables parallel tool calls where Claude Code defaults to sequential
- Spec-first: hand the agent a spec, it runs with minimal interruption
- Emerging as a lightweight alternative to heavier harness wrappers

## Why clawfit should care
Superlite represents a category of thin harness plugins that enhance base coding agents rather than replacing them. Relevant for scoring `setup_complexity` (low) and `statefulness` (stateless/session). Could merit its own registry entry or inform scoring of Claude Code's plugin ecosystem.
