# Research Watch: Claude Duet

- Repo/Link: https://claude.com/product/claude-duet
- Source: Hacker News

## Why this is worth watching
Claude Duet is Anthropic's new pair-programming product that lets a human and Claude collaborate on code in real time within a shared environment. It represents Anthropic's move from chat-based interaction to a continuous co-authorship model. The product surfaced on HN's front page and signals a tightening loop between agent runtime and IDE.

## What stands out immediately
- Branded as "Duet" — implying a synchronous, collaborative session rather than async agentic runs
- Positioned alongside Claude Code as a distinct Anthropic coding surface
- Likely targets developers who find full agentic autonomy too unpredictable but want tighter integration than a chat interface

## Why clawfit should care
If Claude Duet represents a new category between "chat assistant" and "fully autonomous coding agent," clawfit may need a new level in its 7-layer taxonomy to capture semi-autonomous pair-coding products. It also affects scoring: latency and interactivity become primary dimensions for this class.
