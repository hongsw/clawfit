# Research Watch: hyperframes — HTML-to-Video Renderer for Agents

- Repo/Link: https://github.com/heygen-com/hyperframes
- Source: GitHub Trending (+2627 stars today, 47k total)

## Why this is worth watching
hyperframes is the highest-velocity trending repo today by new stars. It lets developers write HTML and render it as video, explicitly targeting agents as the consumer. HeyGen is an established video AI company; this is their OSS infrastructure play for the agentic video generation pipeline.

## What stands out immediately
- Write HTML → get back video frames/clips
- Designed for agents generating video content programmatically
- TypeScript, from HeyGen (production-grade AI video company)
- +2627 stars in one day — exceptional momentum
- Positions as the "browser-use for video" pattern

## Why clawfit should care
Introduces a new output modality layer: agents that produce video rather than text/code. This doesn't map cleanly to existing scoring dimensions (tasks, network, latency). If video-gen agents become a recommendation category, org_fit.tasks needs a "video-gen" value and the taxonomy needs a multimodal output layer.
