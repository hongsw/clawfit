## Why this is worth watching
A comprehensive hands-on curriculum for AI engineering — covering agents, RAG, LLM APIs, evals, and deployment — reached GitHub Trending with 20k+ stars. This is the same trajectory as `claude-code-best-practice` (43.7k★) and `gsd` (52k★), which both graduated to L3 registry entries. Unlike those, this one targets the learning phase rather than production workflow methodology, which fills a distinct gap in the L3 layer.

- Published by an independent developer (rohitg00), not a vendor or major org
