# Research Watch: claude-code-templates

- Repo/Link: https://github.com/davila7/claude-code-templates
- Source: GitHub Trending

## Why this is worth watching
At 29k stars, this is the most-starred community collection of Claude Code configurations — agents, slash commands, MCPs, hooks, and settings templates. It functions as a marketplace-before-there-is-a-marketplace: developers pull battle-tested harness components rather than writing them from scratch. The companion site (aitmpl.com) lets users browse and install 100+ components via CLI.

## What stands out immediately
- Pre-built domain agents (security auditor, performance optimizer) plug directly into Claude Code's `--agent` flag
- Session analytics dashboard with remote monitoring — tracks AI session cost and duration
- MCP integrations for GitHub, Postgres, Stripe, AWS bundled as ready-to-drop config
- Plugin management dashboard and health-check diagnostics suggest growing ops surface
- MIT license, active maintenance, 3.2k forks indicate high community adoption

## Why clawfit should care
This is a Layer 2 harness aggregator — it competes with / complements `superpowers`, `oh-my-claudecode`, and `ralph-claude-code` in the registry. The 29k-star signal suggests it is becoming a default onboarding path for Claude Code users. It could serve as a source for discovering new agent archetypes (tasks, roles) to add to the scoring taxonomy.
