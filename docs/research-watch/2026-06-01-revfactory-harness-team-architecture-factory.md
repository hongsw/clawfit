# Research Watch: revfactory/harness — Team-Architecture Factory

- Repo/Link: https://github.com/revfactory/harness
- Source: GitHub Trending

## Why this is worth watching
revfactory/harness is a Claude Code plugin that automates the creation of domain-specific agent teams: input a domain description, output a complete set of coordinated specialist agents with their skills already defined. At 4.5k stars it is a mid-tier signal for the L3 meta-factory sub-type — the pattern of using agents to generate other agents' architectures.

## What stands out immediately
- Six team architecture patterns: pipeline, fan-out/fan-in, expert pool, producer-reviewer, supervisor, hierarchical delegation
- Full six-phase generation workflow: domain analysis → team design → agent definition → skill creation → integration → validation
- Dry-run testing and before/after performance comparison built in
- Context-efficient progressive disclosure for generated skills
- Self-described as occupying "L3 Meta-Factory" layer — explicitly aware of the ecosystem taxonomy

## Why clawfit should care
revfactory/harness is the second meta-factory signal after Archon (tracked 2026-04-11, deterministic harness builder). Where Archon focuses on runtime configuration, revfactory/harness focuses on team-architecture design — they are complementary tools at L3. The explicit self-classification as "L3 Meta-Factory" is a signal that L3 vocabulary is becoming community-adopted. For clawfit: agent teams generated by this tool would need to be evaluated as composite units, not individual agents — a recommendation dimension not currently in the scoring model.

Current best reading:
