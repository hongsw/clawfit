# Research Watch: Anatomy — Interactive Diagram Agent Skill

- Repo/Link: https://github.com/wheresryan22/anatomy
- Source: GeekNews (news.hada.io)

## Why this is worth watching
Anatomy is a coding agent skill that takes a technical concept (cache, connection pool, etc.) and generates an interactive 3D diagram to explain it. It shows the skill layer maturing beyond text manipulation into structured visual output, with the agent as the author of explainable artifacts rather than just code.

## What stands out immediately
- Targets explanatory and educational output, not production code — a distinct task dimension
- Implemented as a skill (pluggable, reusable) rather than a standalone tool
- Bridges coding agent output with interactive UI generation

## Why clawfit should care
Skills that produce non-code structured artifacts (diagrams, slides, UI components) represent a growing task category. Clawfit's task taxonomy currently focuses on code-gen, research, and summarization — an `explanation` or `visualization` task type may warrant addition. This entry illustrates the skill-layer at Level 2.
