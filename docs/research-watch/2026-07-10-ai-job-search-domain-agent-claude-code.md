# Research Watch: ai-job-search — Claude Code-Based Job Application Agent

- Repo/Link: https://github.com/MadsLorentzen/ai-job-search
- Source: GitHub Trending

## Why this is worth watching
A domain-specific job-search harness built directly on Claude Code reached 18,931 stars with +3,716 in a single day, signaling strong demand for vertically-specialized agent frameworks. It demonstrates the "Claude Code as execution platform" pattern becoming a repeatable archetype beyond software development tasks.

## What stands out immediately
- Purpose-built for non-developer end users (job seekers), not devs configuring agents
- TypeScript, built on Claude Code as primary execution backend
- Application pipeline automation: resume tailoring, portal scraping, offer evaluation
- Rapid trending velocity suggests product-market fit in consumer agent space

## Why clawfit should care
This is a reference data point that domain-specific L1 agents (career/legal/research) are emerging as their own category alongside coding agents. Scoring dimensions for `tasks` should account for non-code tasks (job-search, content-ops, career workflows). The registry's current task taxonomy (`code-gen`, `research`, `qa`, `summarization`) may need a `content-ops` or `domain-specific` tag.

## Preliminary interpretation
Current best reading:
- **Level 1 — Domain-Specialized Base Agent** (job-search vertical, Claude Code backend)
- Closest existing registry entry: `career_ops` (GoLang skill pack) — but ai-job-search is a full harness, not a skill pack
