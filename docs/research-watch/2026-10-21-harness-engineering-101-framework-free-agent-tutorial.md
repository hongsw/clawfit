# Research Watch: Harness Engineering 101

- Repo/Link: https://github.com/IsuruMaduranga/harness-engineering-101
- Source: GeekNews

## Why this is worth watching
A 16-chapter tutorial showing how to build AI agents in ~300 lines of pure Python, with no frameworks. It targets developers who want to understand harness internals before adopting an abstraction. Signals growing demand for first-principles agent education as framework complexity rises.

## What stands out immediately
- No LangChain, no LlamaIndex — pure stdlib Python
- 16 chapters covering tool use, memory, multi-step reasoning
- Aims to make agent internals legible before adding abstractions
- Trending on GeekNews front page, indicating broad developer interest

## Why clawfit should care
This positions "harness from scratch" as a competing mental model to framework adoption. Developers who learn this pattern may prefer simpler, low-overhead harnesses. It reinforces clawfit's scoring emphasis on `setup_complexity`: tools that expose internals (like Claude Code) will appeal to this audience.
