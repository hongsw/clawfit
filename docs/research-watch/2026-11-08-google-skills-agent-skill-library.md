# Research Watch: google/skills — Agent Skills Library

- Repo/Link: https://github.com/google/skills
- Source: GitHub Trending

## Why this is worth watching
Google has open-sourced a curated library of Agent Skills targeting their own products and technologies, joining Anthropic and mattpocock in what is becoming a de-facto skills ecosystem. With 23,386 stars and 443 added today, adoption velocity is high. It signals that the major harness vendors are racing to capture the skills layer.

## What stands out immediately
- Official Google authorship — covers Drive, Workspace, Cloud, Maps APIs
- Python implementation, paralleling anthropics/skills and google's existing SDK conventions
- Pure skills definitions with no harness lock-in; composable with any agent runtime
- Trending alongside anthropics/skills and mattpocock/skills simultaneously — a skills layer consolidation moment

## Why clawfit should care
The skills layer is Level 2 in the 7-layer taxonomy. google/skills expands the catalog of composable, harness-agnostic capabilities a developer can bolt onto any agent. clawfit should track it as a peer to `anthropics/skills` and `mattpocock/skills`, which are already in the registry. If Google products are in-scope tasks (Workspace, Cloud), this becomes a first-party recommendation for those setups.
