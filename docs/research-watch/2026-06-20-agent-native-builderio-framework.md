# Research Watch: agent-native (BuilderIO)

- Repo/Link: https://github.com/BuilderIO/agent-native
- Source: GitHub Trending

## Why this is worth watching
BuilderIO — makers of Mitosis and a leading visual development platform — has published an opinionated framework for building "agent-native" applications (1,033 stars, TypeScript). Their move into agent infrastructure signals that established developer-tooling companies are now designing SDKs for the agent-first product paradigm rather than retrofitting existing frameworks.

## What stands out immediately
- TypeScript, matches BuilderIO's existing ecosystem footprint
- "Agent-native" framing: apps designed from the start for AI agent interaction, not adapted afterward
- From a VC-backed commercial open-source company with a track record of influential tooling (Mitosis, Builder.io CMS)
- Relatively early (1k stars) but organizationally credible

## Why clawfit should care
If agent-native frameworks gain adoption, they shift which tools developers use to build apps — and therefore change which agents need to integrate with those apps. clawfit's Level 1–2 tool taxonomy needs to track agent-native SDKs as a distinct architectural sub-type from traditional frameworks.

## Preliminary interpretation
Current best reading:
- **Level 1–2 — Base Agent / Harness Layer** (agent-native application framework sub-type)
