# Research Watch: AI 뭐쓰지? (llm-pick) — Lightweight Model Recommendation Tool

- Repo/Link: https://llm-pick.pages.dev
- Source: GeekNews (Show GN)

## Why this is worth watching
A user-submitted tool on GeekNews that recommends which AI model or service to use for coding, debugging, and docs based on the user's current subscriptions or API access. This is a direct functional analog to clawfit, operating in the same "which AI fits my context" space but oriented toward model selection rather than agent+LLM+hardware stack selection.

## What stands out immediately
- Filters recommendations by what the user actually has access to (subscriptions/API keys)
- Scoped to task types: coding, debugging, documentation
- Lightweight, deployed on Cloudflare Pages (no backend)
- Korean-language community signal suggests adoption spreading outside the English-first developer sphere

## Why clawfit should care
llm-pick is a lightweight competitor or complement. It validates the market for recommendation tooling but operates at a narrower slice (LLM-only, no agent or hardware dimension). Watching its feature evolution could reveal demand signals for simpler onboarding paths in clawfit.
