# Research Watch: Anthropic — Progress on Provable Inference for LLMs

- Repo/Link: https://www.anthropic.com/research/provable-inference
- Source: Hacker News front page (2026-11-05)

## Why this is worth watching
Anthropic's research post describes progress on making LLM inference outputs verifiable — specifically, producing cryptographic or formal proofs that a given output was generated by a specific model under specific conditions, without revealing model weights. This is a structurally new capability layer: not about what a model outputs (accuracy) but about provably binding an output to a model identity and generation context. If this matures into a production API feature, it would affect how clawfit scores models for high-governance profiles.

## What stands out immediately
- Research-stage post (not a production announcement); no shipped SDK or API
- Framing: "progress toward" provable inference, not a complete solution
- Potential applications include: regulatory audits, AI output attribution in legal/financial contexts, model identity verification for multi-agent systems
- Distinct from watermarking (output-level signal that can be stripped) — claims structural binding at the generation layer
- Anthropic is the first frontier lab to publish a named research direction toward provable inference at this abstraction level

## Why clawfit should care
clawfit's `governance_need: hard` profiles (large orgs, regulated industries, `data_sensitivity: confidential`) currently score for model source (open vs. closed) and network containment. Provable inference would add a third governance dimension: output attribution certainty. If Anthropic ships a production API endpoint that returns proofs alongside outputs, `governance_need: hard` scoring logic should weight provably-attributed outputs differently from non-provable ones. This would also affect multi-agent architectures (L3) where verifying which model generated a specific action is a trust boundary concern.
